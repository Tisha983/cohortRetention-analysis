# Excel Cohort Retention Analysis

## Project Overview
Customer cohort retention dashboard built in Microsoft Excel
to analyse month-over-month retention across 5 cohorts.

## Tools Used
- Microsoft Excel
- COUNTIFS, DATEDIF, TEXT formulas
- Conditional Formatting (Heatmap)

## What I Built
- Raw data sheet with cohort month and month number columns
- Cohort count table using COUNTIFS formula
- Retention % table showing churn over 6 months
- Green-White-Red heatmap for visual analysis

## Key Insight
January 2023 cohort retained 50% of customers till Month 3
while newer cohorts dropped to 0% by Month 2 showing
increasing churn in later cohorts.
